# HCI Lab + IA

Laboratorio educativo de interacción humano-computador, UX, accesibilidad e IA responsable. React y TypeScript; proyecto guardado en el navegador y respaldable en JSON.

Versión **2.5.0** preparada localmente, sin publicar. [Estado de cumplimiento y pendientes](docs/cierre-integral.md) · [Persistencia y privacidad](docs/persistencia-privacidad.md).

[Español](README.es.md) · [English](README.en.md) · [Português](README.pt-BR.md) · [Français](README.fr.md)

Con Node.js 22.12 o posterior, desde la raíz:

```powershell
npm ci
npm run dev
```
