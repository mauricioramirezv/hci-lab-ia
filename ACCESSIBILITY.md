# Accessibility statement

HCI Lab + IA targets WCAG 2.2 Level AA as a teaching baseline. The application includes keyboard operation, visible focus, semantic landmarks, accessible names, live regions, text enlargement, high-contrast themes, reduced motion and configurable reading spacing.

Automated checks do not replace manual evaluation. Test with keyboard, 200% zoom, NVDA, VoiceOver or TalkBack, and people with diverse needs. The LSC interface accepts an expert-reviewed sample video; it does not claim automatic Spanish-to-LSC translation.
