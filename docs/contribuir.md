# Contributing

1. Create a branch: `git switch -c feature/short-name`.
2. Keep visible strings in the six language resources.
3. Add or update tests for each behavior.
4. Validate keyboard use, focus, 200% text size and responsive layouts.
5. Run `npm run lint`, `npm test`, `npm run build` and the relevant E2E checks before opening a pull request. See the [test guide](pruebas.md).

AI-generated content must include its prompt, provider, date and human validation decision.
